# Branding and independence

This is an independent Black Swamp AI community integration. It is not affiliated with, endorsed by, sponsored by, or maintained by Geoapify. Geoapify's name is used to identify the compatible service; Geoapify marks belong to their respective owners.

## Packaged icon assets

The current Geoapify site references vendor favicon/icon assets, but the reviewed source did not provide a clear grant for reuse as an integration logo. To avoid implying official status or assuming trademark permission, the package uses an original neutral location-pin icon. It does not reproduce or recolor a Geoapify mark.
